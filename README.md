# 핏빛 카타콤

도트 감성의 디아블로풍 멀티플레이 액션 RPG. 최대 4명이 파티를 맺고 100층 지하묘지로 내려갑니다.

- 서버: `node server.js` (외부 패키지 없음, Node 18 이상)
- 접속: `http://localhost:3000`
- 캐릭터는 각 브라우저에 저장되며, 저장 코드로 다른 컴퓨터에 옮길 수 있습니다.

## Render 배포
New → Web Service → 이 저장소 선택 → Build Command는 비워 두거나 `npm install`, Start Command는 `node server.js`, Instance Type은 Free.
